# A/B-тест геймификации на образовательной платформе

Анализ влияния фичи геймификации на Completion Rate и Retention 7/14. 
Учебный проект в рамках VK Education Projects.

## Ключевые результаты

Фича показала статистически значимый рост на всех трёх метриках:

| Метрика | Группа A | Группа B | Δ, п.п. | p-value |
|---|---|---|---|---|
| Completion Rate | 97.63% | 98.83% | +1.20 | 4.2e-04 |
| Retention 7 | 72.71% | 77.96% | +5.26 | 2.4e-06 |
| Retention 14 | 28.94% | 36.43% | +7.50 | 6.9e-10 |

Эффект устойчив в подгруппах по стажу. Разбивка по классам показала неоднородность: сильный эффект в младших классах (+16.1 п.п.), умеренный в средних (+5.4 п.п.), в старших не подтверждён (−3.7 п.п., p = 0.089).

**Рекомендация:** раскатить фичу на 100% пользователей. Старшие классы (10-11) требуют отдельного мониторинга.

## Артефакты

- [`ab_test.ipynb`](ab_test.ipynb) — Jupyter Notebook с полным анализом: очистка данных, проверка баланса, расчёт метрик, z-тесты, доверительные интервалы, MDE, воронка, сегментация по классам.
- [`ab-test-presentation.pptx`](ab-test-presentation.pptx) — презентация для стейкхолдеров (13 слайдов).

## Данные

Датасет предоставлен в рамках курса VK Education Projects и не распространяется. 
Чтобы воспроизвести анализ, положите два CSV-файла в папку `data/`:

- `ab_test_users_groups.csv` — принадлежность пользователей к группам, signup_date, grade.
- `ab_test_events.csv` — логи событий за период эксперимента.

Период эксперимента: 2026-05-04 — 2026-05-24 (20 дней).

## Методика

- **Метрики:** Completion Rate, Retention 7, Retention 14.
- **Тест:** z-тест для двух пропорций (pooled variance), двусторонний, α = 0.05.
- **Доверительные интервалы:** 95%, для разности долей (unpooled SE).
- **MDE:** рассчитан для каждой метрики при мощности 80%.
- **Поправка на множественные сравнения:** не применялась. Обоснование в ноутбуке, блок «Методика».

## Что внутри ноутбука

1. Загрузка и первичная разведка.
2. Очистка данных: дубли user_id, дубли событий, неполное окно d14.
3. Проверка баланса групп: SRM, grade, стаж.
4. Расчёт метрик с доверительными интервалами.
5. Статистические тесты (z-тест).
6. MDE.
7. Проверка устойчивости по бакетам стажа.
8. Анализ воронки (логин → начали ДЗ → завершили ДЗ).
9. Сегментация по классам (post-hoc, exploratory).
10. Вывод и рекомендация.
